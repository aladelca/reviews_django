# Reviews Django Application

A minimalist web application for managing product/service reviews built as part of an Artificial Intelligence course at Cibertec Lima, Peru.

## Technology Stack

### Backend
- **Django** - Python web framework for rapid development
- **Python** - Core programming language
- **SQLite** - Default database for development (Django's built-in database)

### Frontend
- **HTML5** - Semantic markup structure
- **CSS3** - Modern styling with:
  - CSS Grid and Flexbox for responsive layouts
  - CSS Variables for consistent theming
  - Backdrop filters for glass morphism effects
  - CSS Transitions and animations
- **Django Templates** - Server-side template rendering

### Design System
- **Minimalist UI** - Clean, modern interface design
- **Dark Theme** - Elegant dark color scheme with white accents
- **Responsive Design** - Mobile-first approach with media queries
- **Glass Morphism** - Modern design trend with backdrop blur effects

### Development Tools
- **Django ORM** - Object-relational mapping for database operations
- **Django Forms** - Built-in form handling and validation
- **CSRF Protection** - Cross-site request forgery protection
- **Template Inheritance** - Reusable template components

## Features

- **Review Management**: Add, view, and list product/service reviews
- **Responsive Interface**: Optimized for desktop and mobile devices
- **Form Validation**: Client and server-side form validation
- **Modern UI**: Glass morphism design with smooth animations
- **Spanish Localization**: All content in Spanish for local users

## Design Philosophy

This application follows a minimalist design approach with:

- **Clean Typography**: Arial font family with proper letter spacing
- **Subtle Animations**: Smooth hover effects and transitions
- **Consistent Spacing**: Uniform padding and margins throughout
- **Accessibility**: Proper contrast ratios and semantic HTML
- **Performance**: Optimized CSS with minimal external dependencies
